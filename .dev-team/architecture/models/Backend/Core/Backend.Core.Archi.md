# Backend.Core.Archi

## 职能

架构模型的纯读域。它把 `<架构域>/graph/model/*.toml` 解析成内存里的元素 / 关系图，再向上
提供同一份结论——五个消费面（进程内结构校验、agent 的 `archi_*` 工具、IPC 命令面、架构页
画布、架构漂移门禁）都从这里取数、取词、取判定。另外它承载模块 API 契约面：装载手写的接口
定义、抽取代码里真实的导出面、求值判据、装配生成物，但一律只出内容，不落盘。

**边界**：零 UI 框架、零库句柄、零子进程、零工作流与编排 crate 依赖、零工作区配置读取；
只读盘不写盘。模型写回的产物由壳层命令面落盘，契约生成物与漂移报告的落盘在 infra 侧，
本 crate 只交文本与结构。依赖方向单向：只依赖 `foundation`（目录布局与取消两半），不依赖
任何上层 crate——所以它能被判定域之外的每一个驱动面直接调用。

## 面地图

子模块均在 `crates/core/archi/src/` 下。

| 面 | 位置 | 职责 |
|---|---|---|
| 解析 | `parse/`、`model.rs` | TOML → 格式无关 AST；多文件按文件名序合并；九类结构诊断 |
| 图 | `graph.rs` | 唯一建图点：节点 / 边 / 出入边索引 / 1-hop 邻域；环经强连通分量检出 |
| 词汇与投影 | `dto.rs` | 封闭词汇的全量单点 + 全部线面类型 + 图 / 详情 / 概览 / 检索 / 变更摘要 |
| 结构差异 | `diff.rs` | 两模型的元素增删、关系计数、gate 变更（全零即等价） |
| 检索语料 | `search.rs` | 元素与在盘资产路径的命中集（驼峰分词，空白 query 即错） |
| 文件树 | `tree.rs` | 磁盘枚举 + 模块根标记 + 归属与后代计数（遍历、归属、排除全经 `scan/`） |
| 关系详情 | `relation.rs` | 单条关系的按需事实取样：模型面 + 事实面 + 两桶 + 命中点，不组装报告 |
| 扫描 | `scan/` | 遍历（gitignore 感知）→ 排除 → 归属 → Rust / TS 两套依赖抽取 → 跨元素边聚合 |
| 判定 | `drift/` | 看护配置 + 对账 / 定级 / 豁免 / 两桶 / `status` 推导 + 报告词汇 |
| 写回原语 | `edit/` | 文本级改写 + 读盘定位 + 反馈面，产出待落盘文本而非落盘 |
| 契约面 | `api/` | 接口装载与校验、声明抽取、生成物渲染、十条判据、三类差异、入口解析、路径派生 |

## 承载理由

- **五面同源，所以只建一次图**：结构校验、画布、检索、详情、漂移判定读的是同一份模型。若
  各自解析、各自建图，同一份 TOML 在不同面就会给出不同结论（谁算祖先、谁是歧义归属），
  而这类分叉只在最难查的时候暴露。因此解析、图、投影、判定、写回原语同居一个依赖最底的
  域 crate，消费面一律经投影入口取数。
- **两种语言的语法必须真解析**：契约面要回答「代码里实际导出了什么」，漂移面要回答
  「哪个文件 import 了哪个元素」。正则做不到这两件事（别名重导出、`use` 树、`#[path]`
  都会骗过它），起子进程问工具链又被「零子进程」挡死——于是 Rust 与 TS 各一套语法解析器
  是这里最重的一笔第三方依赖，且各自只有一处入口。图算法（成环、邻域）、TOML 原位改写、
  gitignore 感知遍历同款：都不是通用工具库，是这几条判据的必需品。
- **判定在域里，执行在 infra**：漂移判定是纯函数——输入是根目录与模式，输出是报告结构。
  命令面、agent 工具、门禁 runner、CLI 四个驱动面都只调同一处，结论因此可逐字比对；一旦
  判定域自己握住写盘或子进程，「读了 A 却写了 B」的顺序耦合就会长进判定内部，四个面再也
  对不齐。
- **契约的真相搬到了接口文件**：早先导出名清单写在文档的 `api-*` fence 里，生成物照着
  fence 渲染。两处各写一份必然漂移，于是拓扑归模型 TOML、接口归同目录 `<FQN>.schema.json`
  （唯一凭据）、理由归 `<FQN>.md`（纯散文、读面零解析）。历史 fence 按普通正文对待，不读、
  也不再新增——文档的职责是讲清为什么这样切，不是复述导出名。
- **冷启动是合法起点，不是错误**：模型目录缺席或空目录 → 空模型零诊断；看护配置缺席 →
  空配置；接口面未启用 → 判据返回空集且既有漂移语料逐字不变。三处都靠「缺失即空」把首次
  进入和配置写坏区分开——前者静默，后者一律停给用户看。

## 不变量

解析与图：

- **目录缺席与停摆可分**：模型目录不在或零个 `.toml` 是空模型（零诊断）；单个文件读不出来
  必报 `syntaxError`，MUST NOT 静默丢文件；跨文件重复 FQN 逐条检出。
- **值域封闭且错误带全量**：未知键、缺必填、值不在封闭值域都各成一类诊断，值域类错误列出
  全部合法值。诊断九类之外不设「其它」。
- **只有两端都已声明的关系入图**：未定义引用的边留给诊断，不进图；环按强连通分量判，不靠
  深度遍历撞运气。
- **结构诊断非空即停摆**：图投影退化为空集合加诊断清单，派生读面（详情 / 文件树）直接报错。
  残缺图的读法本身歧义（环画成什么样、悬空边画在哪），有精确行号时读文本更快。

投影与确定性：

- **投影零改写**：只裁剪（1-hop、字段子集），不重算、不推导、不补默认值——可空字段显式给
  `null` 而不省略键，前端因此不必区分「没有」与「默认」。节点集合用有序容器承载，条目按
  FQN 或路径字节序输出，同输入同输出。
- **归属单源**：归一化、剥离、最长前缀、后代计数只有一份实现，文件树与漂移判定必须对同一
  个文件给出同一个归属。同长多命中记「歧义」，MUST NOT 任选一个。`gate = off` 的元素照样
  参与归属（只是不参与定级），它的依赖事实照常抽取。
- **生成物按三候选并集归属**：`<name>.i.<ext>` 既可能落在元素根内、也可能替换扩展名、也可
  能与文件型 `path` 的主干对齐——三种落点互不相交，故三个候选各跑一遍再合并，不做候选短路。
- **排除只追加不替换**：七条默认约定（测试文件、测试目录、装置、mock、Rust `_test.rs`）之
  后才接配置里的 `exclude`；排除面与工作区测试 scope 零耦合，且配置条目必须是文件级 glob
  （无通配符即错），拼错的排除规则必须停给用户，不许静默失效。

扫描与判定：

- **扫描只出事实，判定只出结论**：文件归属、跨元素依赖、排除与未解析留痕都在扫描；对账、
  定级、豁免、`status` 只在判定。`unresolved` 一律留痕（宏生成的模块、`include!`、孤儿文件、
  `use` 解析失败），外部 crate 静默丢弃——没有元素覆盖的第三方依赖记进报告只是噪声。
- **定级只看引入方**：违例挂在哪一侧的档位上，由引入方元素决定，被引入方的档位不参与。
- **豁免三层，全部留痕**：声明本身即第一层豁免（模型写了这条边就合法），配置里的元素对豁免
  是第二层，行尾内联注释是第三层。粒度只到「元素对」，MUST NOT 退化成 glob 或单边；豁免
  必须带理由，理由空白即配置非法。被抑制的条目带来源与命中点出线，不凭空消失。
- **名字级两桶只对写了 `apis` 的关系**：`used ∖ declared` 按引入方档位定级；`declared ∖
  used` 永只是观察项，不进 `status`、不进 `passed`——代码少用一个导出名是常态，不是架构债。
  声明关系而代码无该依赖同属观察项。
- **`status` 五值，两值不得当作通过**：`noChanges`（无文件可判）与 `skipped`（无模型）都
  MUST NOT 被呈现或消费为「通过」。报告带版本号，消费方按版本分支，MUST NOT 给旧报告补
  默认值。

写回原语：

- **三层形状固定**：文本级改写只碰字符串（零文件系统）、计划层读盘定位（先结构诊断前置，
  再存在性与落点，再读源） 、反馈面只重述既有判据的词。零写盘、零子进程、零 Tauri。
- **自证链不许跳过**：产出顺序固定为「改 AST → 渲染 → 表头计数回填 → 重解析零诊断 → 回读
  逐字段一致」，且被自证、被回读的文本逐字等于交出去的文本——MUST NOT 先验后改。
- **三态语义**：省略 = 不动、空值 = 清键、给值 = 设值。封闭枚举位没有清空臂。写面 MUST NOT
  产出被解析器判非法的形态（例如渲染空数组），越界值经自证链变成显式错误。
- **同名关系多处声明即停**：同一 `(from, to)` 在模型里出现第二处，改哪条、删哪条都是静默裁决，
  故 fail-closed。级联删除只承诺同一模型文件内的子树与出入边，闭包跨文件即报错并点名。

契约面：

- **零 md 回落**：读面只从接口文件取接口事实，文档正文不被读取。接口文件不在盘 = 该元素
  「接口未写」（零判据）；在盘但校验失败 = 停摆（不产半真报告）。
- **`api = none` 是显式留白**：断言本模块无公共 API。留白元素在派生路径上冒出接口文件即违约；
  「没有门」与「明说无公共 API」是两个事实，MUST NOT 互相冒充。
- **判据十条、分组七个，档位单点**：档位只有一处定义——`error` 恰两项（声明未兑现、签名
  不符），`off` 恰一项（代码有未声明的外部面），其余七项 `warn`。两处 `error` 都以「接口
  文件在盘且过校验」为前提，这是「`status = errors` 等价于 `passed = false`」的结构性保证。
- **文档债永不纳管**：文档不在盘恒为 `warn`，既不进 `status` 也不进 `passed`。否则存量文档债
  会把状态词常规化为永久 `warnings`，门禁形同废纸。纳管口径只有一条：接口承诺已成立（声明
  了接口且接口文件在盘）。
- **启用是一次性整体开关**：任一有路径的已声明元素在盘有接口文件 ⇒ 接口面启用，此后全部有
  路径的元素纳入判据，无白名单、无部分豁免。散落的无关文件与留白元素的接口文件都不是启用
  证据。
- **入口解析三态**：显式指针、约定默认、不可用。不可用恰四种理由（形态不符、落在本元素路径
  之外、不在盘、与另一元素解析到同一文件），只经接口判据出线——不进结构化诊断，否则一条坏
  入口会把整张图拖进停摆。「不可用」是合法终态（该元素不参与契约面），MUST NOT 拿留白冒充。
- **生成物三类，写盘另处**：索引、Rust 侧生成模块、TS 侧生成模块；后两者落在实现入口同级，
  索引落在架构域。手写的接口文件与文档不在应生成集——进了就会让生成覆写手写真相。比对只出
  三类差异（内容不符 / 应删未删 / 应生成未生成），写盘单点在 infra，CLI 与两条 IPC 同源。
  接口无 op 也无类型时跳过生成模块（零导出的生成物会让入口的再导出触发未使用告警）。

## 契约面

本模块自身的公开面同样受契约词汇的限制：契约能表达值的形态，没有「路径」这个位置，也没有
「引用一个已经存在的类型」的位置。因此只涉及标量的操作进契约面，入参或返回是路径、借用
字符串、具名类型、以及零返回的设置动作一律留白——硬写进契约，两侧签名核对永远是红的。要
补齐得先扩契约词汇，而不是把判据放松。构造器按纪律不进契约。

`owner` 键填「方法挂在哪个类型上」或「函数在哪个子模块」，不填 FQN——它唯一的用处是在生成
物里拼出 `<owner>::<op-id>` 的限定写法做编译期核对。

## 类型

封闭词汇分两处，各自持一份全量常量，新增变体必须同补（长度即红灯），词汇对拍覆盖全部取值：

- 模型与投影侧九个：元素种类四值、gate 三值、接口状态二值、结构诊断九类、边标记四值、节点
  标记二值、文件条目形态二值、文件树标记五值、检索范围三值。
- 判定侧四组：结论状态五值、漂移条目五值、观察项二值、接口判据十值。

四组 MUST NOT 复用结构诊断的词汇——混用会让「模型写坏了」和「代码违背了声明」在类型上不可
辨，而这两类要走完全不同的处置路径。

出线类型一律带 `Archi` 前缀：类型注册表按裸名唯一，进程内仍按短名引用。进 `$defs` 的只有
跨过元素边界时真正接触的形态；模型 AST、内存图、结构差异、写回产出是进程内类型——不做序列
化、不进进程间调用，也不出现在任何已声明操作的签名里，形状由代码负责，契约不管。
