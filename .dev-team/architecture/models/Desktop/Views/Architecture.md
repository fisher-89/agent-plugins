# Desktop.Views.Architecture

## 职能

架构页整页视图：路由 `/architecture` 挂载，`root` 即工作区根。左栏是可折叠的「架构 Agent」
会话面，右栏是架构画布——左栏三视图分段控件（元素 / 文件 / 契约）、xyflow 邻域关系图、
同一面板位的元素态 / 关系态信息面板，三者构成「选什么 → 看什么」的单向流。

**边界**：零判定、零读盘、零后端规则。取数只经生成绑定命令，漂移与结构错的判定在后端纯函数
（`desktop-archi-drift` / `desktop-archi-model`），本元素只把报告折成边标记与展示投影。会话
状态机不在此（复用 `useAgentSession`），面板骨架是 `Desktop.Components.Agent.SessionPanel`。

## 页壳与停摆

- **布局**：横向 `ResizablePanelGroup`，左会话面 + 右画布（右栏 `minSize="40"`，其内画布包一层
  `pl-1.5` 容器）。
- **刷新单入口**：页头刷新只递增 `refreshTick`，画布以 `key={refreshTick}` 重挂载——图、漂移、
  文件树、契约检查随之一起重取。这是刻意设计：文件树 hook 因此**不暴露** `refresh` 成员，避免
  长出第二个触发入口。
- **五分支早退，判序固定**：首轮取数中（「解析中…」）→ 图取数失败（行内红块）→ 无工作区根 →
  结构错停摆（只渲逐条 `kind` + `file:line` 的错误面板）→ 模型为空（提示先跑 dev-design 生成
  骨架，新元素缺省 gate = off）。「无根」排在取数两态之后不是笔误：无根时图恒为 `null` 而
  `loading` / `error` 都为假，自然落到第三支。
- **停摆是全或无**：结构错未消除前零节点、零边、零降级样式、零占位节点——残缺图的读法本身歧义
  （环画成什么样、悬空边画在哪），而结构错都有精确行号，读文本比读畸形图快。

## 取数纪律

- **三触发、零 watch 零轮询零定时器**：挂载 / `root`（或 `mode`）变化 / 手动刷新。`root === null`
  一律零 invoke。
- **键守门，旧结果不冒充本次结论**：每个 hook 都记住「结果属于哪个键」，键不符即返回 `null`。

  | 取数面 | 已载入键 | 失败行为 |
  |---|---|---|
  | 图 | `root` | 行内红块，画布停摆 |
  | 漂移 | `mode:root` | 清空报告，零标记图 + 行内提示 |
  | 文件树 | `root` | 清空树，行内（画布照常） |
  | 契约检查 | `root` | 清空三类差异，行内（画布照常） |
  | 元素详情 | `root` + `fqn` 组合键 | `Alert` 行内 |
  | 关系详情 | `root` + `from` + `to` 组合键 | 行内错误 + 重试入口 |

- **失败面相互独立**：漂移 / 文件树 / 契约检查 / 关系详情任一失败都不阻断图与面板，只有图自身
  失败才停画布。
- **关系详情按需取数**：`apis` 为空的边零 invoke（没有可比对的清单，取数只是空转）；同一元素对
  经引用缓存复用、零重复 invoke；触发面恰为「选中边变化」与「用户点重试」。

## 左栏三视图

分段控件三段（缺省元素视图），切换只换左栏组件、`focus` 共用，取数失败只落本栏行内。

- **元素视图**：由 FQN 前缀派生（父 = 最长已声明前缀，逐段 pop 直到命中），兄弟按 FQN 字典序；
  四种 kind 各有图标（package / domain / module / composite）；**默认全展开**，无子节点时 chevron
  `opacity-0` 且禁用；节点名取末段短名；空态「模型内暂无元素」。
- **文件视图**：后端只给扁平条目，层级 / 兄弟序 / 缩进 / 展开态全由本件派生。兄弟序恒为
  **目录优先、同类按名**。展开判定三级优先：聚焦锚点及其祖先链强制展开 > 用户逐路径翻转态 >
  默认「路径段数 ≤ 3 展开」。**锚点之下不下钻**（不覆盖用户翻转态），并滚动到首个锚点（分组
  多路径元素会有多条锚点）。
- **文件视图的三个归属标记**：`elementRoot`（「模块 <末段>」按钮，点击切聚焦，聚焦时变主色）、
  `ambiguous`（destructive 徽章「多归属」，title 列全部归属元素）、`containsElements`（secondary
  徽章 +N，title「含 N 个模块」）；`member` / `none` 不渲标记节点。声明了但磁盘不存在的条目标红
  「缺失」。
- **文件视图整行点击两义**：归属行（`elementRoot` / `member`）点击 = 把聚焦圈定到 `owners[0]`；
  非归属但有子节点 = 切换展开。chevron 上阻断冒泡，否则一次点击翻转两次。
- **契约视图两轴并列**：上轴 = 生成物新鲜度（不符 / 孤儿 / 缺失三组，合计只在此轴出现）；下轴 =
  契约判据（chip 由 `category` 派生，零前端词表，空类别不渲 chip）。**MUST NOT 出现跨轴合并
  总数**——两轴可修复者不同（一轴机器可修，一轴要人或 agent 修）。
- **生成入口只在 `incremental`**，且二次确认会把三件事写死：写入份数、保留孤儿数、写盘非原子。
  `check` 未回时入口在场但禁用（入口缺席会被误读成「不能生成」）；`full` 模式改显提示「生成需
  开 change（或让左侧会话执行本仓的生成命令）」。生成成功走 `notify` + 本面板刷新，不触发全局
  重挂载。

## 画布与边标记

- **邻域三项**：聚焦元素的出边目标、入边来源、直接子元素——只有这三类入图。
- **纯拓扑布局，零布局引擎**：聚焦居中；出边列在右（有子节点时让到分组右缘之外）、入边列在左，
  两列各按分组高度垂直居中；子元素在聚焦节点内容区内自上而下堆叠。步长 240 / 96，分组尺寸
  240 宽 × 标题栏 + 留白 + 行高累加；初视口 `fitView`（留边 0.2，缩放 0.2–1，单节点不过度放大）。
- **入边分区**：框住整列入边节点的虚线框「被以下模块引用」，纯背景装饰——不进节点集、不响应
  点击（`pointer-events-none`），无入边即无分区。
- **交互面刻意收窄**：节点不可拖、不可连；滚轮不缩放、双击不缩放，滚动即平移。点节点 = 清选中
  边 + 切聚焦；点边 = 选中该边。
- **边标记单源且只产边**：漂移报告只折两段——`unfulfilledDeclaration` 观测 → `unfulfilled` 边、
  `suppressed[]` → `exempt` 边（理由与来源 `config` / `inline` 随面板呈现）；同一元素对冲突取
  `unfulfilled`。MUST NOT 改写元素 `mark`：画布与元素树都不呈现节点标记。
- **边样式四值封闭**：`none` 实线 / `unfulfilled` 灰虚线 / `crossKind` 橙虚线 / `exempt` 灰
  实线；词汇外值退化为中性且不抛错。选中边只加粗既有描边（3px），不换色、不引新标记词汇。
- **节点渲染**：叶子 = 短名徽章，有子节点的聚焦元素 = 分组卡片（标题栏 + 内容区）。两类都挂
  隐形把手——xyflow 无把手就不求边位置，边不入 DOM。

## 信息面板两态

同一面板位互斥两态（无选中 = 元素态，有选中 = 关系态），MUST NOT 另开抽屉或边旁浮卡。

- **元素态段序固定**：概览（FQN / summary / kind 与 gate 徽章 / 源码路径清单，未配置显「（未
  配置）」）→ 取数错误 `Alert` → 契约判据（本元素；空显「本元素无漂移」）→ 入口文档（仅
  `api = none` 元素，无则「无入口文档」）→ 豁免段（无豁免则整段隐藏）→ 改档或只读提示。
- **改档草稿不得跨元素存活**：草稿随元素重挂（`key`）+ 权威档位变化即重取；否则切聚焦后写回会
  把上一个元素的档位写到新元素。只读态文案：「改档需要开一个 change（本页为只读视图）」。
- **关系态七段固定序**：关系（元素对 + 标记徽章）→ 说明（无则让位）→ 声明 API（取图里的
  `apis`，零 invoke）→ 实际使用 → 两桶 → 命中点 → 模型行号。**不自行求差**：两桶是命令返回值，
  本元素 MUST NOT 读漂移报告重算归属。
- **关系态五分支，判序固定**：取数失败（错误块 + 重试）> 已豁免（来源 + 理由，来源未知显「未知
  来源」）> 未声明依赖 API（`apis` 空，标「选填」）> 取数中（「取数中…」）> 四段事实面（实际
  使用 / 两桶 / 命中点 / 模型行号）。命中点段另有自己的空态「扫描面无该关系的 import」。声明
  清单与「声明没用」非空时，附一句三种可能成因（已不再依赖 / 名字写错 / 以方法调用、内联限定
  路径、glob 形态存在而扫描看不见）——不替用户下结论。
- **模型行号是契约面**：`modelFile:modelLine` 恒在场，无根时只禁用「查看」按钮，不静默少渲一行。
- **「接口」tab 是显式留白**：三 tab（文档 / 接口 / 关系图）里，文档 tab 呈契约三路径文件
  （手写契约 / schema / 入口生成物），关系图 tab 是邻域图，接口 tab 正文只有「敬请期待」——尚未
  实现，不是空数据。

## 架构会话面

- **归属固定**：`source = "archi"` / `sourceRef = null` / `cwd = null`（后端回落 workspace root），
  不按来源反查会话；历史清单只是探测面（专用薄命令分页，页宽 20，「加载更多」累加）。
- **清单取数时机收敛两处**：会话 id 由 `null` 变非 `null`（首发后轮行回写铸出的新会话随即出现在
  清单里可点选重开）与 `running` 由 `true` 变 `false`（轮收口）；挂载不触发、零轮询。请求票号
  保证只有最新一拍落地，`root` 变化即作废在途请求——旧根的页不得落新根。
- **判据单源**：`running` 是本面板唯一禁用理由（连「新会话」一并禁，历史浏览恒可用）；空态即可
  发送，首发以 `sessionId: null` 发出由后端铸会话；骨架与 composer 都不自判。
- **状态行三态**：禁用理由优先，否则空态草案文案（「发送首条消息即开启新会话」），否则常驻提醒
  「模型改动不会自动刷新，改完点「刷新」」。
- **会话骨架与输入框复用组件层**：面板只给 `SessionPanel` 喂状态与 composer 插槽，testid 前缀
  `archi-chat`；输入框是 `AgentInput`，含权限档位与停止入口。

## 不变量

- **入口导出面恰为一名组件**：多导一个即虚增公共面（`knip` 判红），少导一个即断路由。内部件
  （画布装配、三视图、两个面板、六个 hook、纯函数）一律不经入口外露。
- **`ArchitecturePanel` 是深路径复用点，不是公共面**：变更详情与 flow 运行控制面板按深路径
  import 它并传 `mode="incremental"`；契约面 MUST NOT 声明它——代码导出集里没有这个名字，声明
  即触发「有约定无兑现」。
- **派生单点**：FQN 短名只经 `shortName`（元素树与画布节点共用，两处各写一份会让同一元素在两处
  呈现不同名字）；树的层级只按 FQN 前缀 / 路径段派生；关系两桶只读命令返回值。
- **能力差异单值**：`full` 只读（本页）/ `incremental` 可改档 + 可生成（变更详情、flow）；
  本页恒传 `full`，一切写命令入口都由这个单值门控。
- **生成物只经既有生成命令重生成**：本元素零手改生成物，只读地呈现两轴读数。

## 契约面留白

- **入口组件不进契约**：形态是「解构的内联对象入参 → `React.JSX.Element`」。两侧归一恒不等
  ——返回位在契约词汇里只能经 `$ref` 落 `?<名>`（`schema_type` 的 `$ref` 分支产 `Unknown`、
  短形带 `?`），代码侧是具名元素类型；入参位是内联对象字面量，代码侧归一为 `?`（`Unknown` 空
  原文），契约侧没有对应的具名 props 类型位。同类实测差异与出路见
  `Desktop.Components.Agent.AgentError` 的留白段。
- **元素内部件不进契约**：上文「部件地图」与各段提到的组件、hook、纯函数都是实现说明，不是公共
  承诺——`$defs` 与本元素的承诺面都为空。
- **类型面为空**：入口零类型导出；`CanvasMode` / `TreeMode` / `EdgeVisual` / `RelationEdge` 等都
  是元素内部事实，不外露即不承诺。

## 类型

本元素自有 `$defs` 为空（公共面只有入口一名组件，且不进操作面，见上）：契约侧不新建类型。

## 承载理由

一页一元素：`/architecture` 是路由挂载点，三视图、画布、两态面板、会话面与六个取数 hook 同处
一个目录，才使「架构页」作为整体被路由引用；其中没有任何部件有独立于本页的公共面——拆出去只会
多出几个无消费者的元素。唯一的跨页复用点（画布装配）靠深路径引用，正好说明了这一点：它需要被
复用，但不需要成为承诺。
