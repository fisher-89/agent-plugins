# 续跑与中断恢复

本 skill 不维护状态文件。所有进度判据来自磁盘，新会话再次调用时从阶段 0 重新进入，据下表自动推进到未完成的阶段。

| 产物 | 存在时的行为 |
|---|---|
| `openspec/test-profile.md` | 跳过阶段 0 的扫描，只做「过期判定」（见 `project-detection.md`） |
| `design.md` | 询问覆盖或沿用（见 `design-template.md` 的「已存在时」） |
| `test-design.md` | 询问覆盖或沿用；新写或改动后须过阶段 3 出口的用户确认（见 `test-design-template.md` 的「确认出口」） |
| 某节的测试文件 | 阶段 4 跳过该节 |
| 突变配置 | 阶段 6 跳过生成，直接告知用户用既有配置 |

## 阶段 4 的批内续跑

每批开始前，检查该节对应的测试文件是否已存在且非空：

```
已存在且非空 → 跳过该节，直接下一节
不存在或为空 → 正常生成
```

一批完成后不要回读已完成的章节，只保留在磁盘上。

## 覆盖率回补中的续跑

阶段 5c 回补到阶段 2/3/4 时，已生成的测试文件仍按上表逐节跳过——只补缺失或需要改的节，不重写全部。
