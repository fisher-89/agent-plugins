# wps-agent-plugin

## 安装

### wps_claude 安装

将本仓库配置为 Claude Code 插件源：

```bash
wps_claude plugin marketplace add https://ksogitlab.kso.net/zhangbohan3/wps-agent-plugin.git
```

安装后，插件会自动加载到 Claude Code 会话中。
